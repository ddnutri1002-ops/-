## 일괄 폴더 생성
Windows PowerShell:
```powershell
$r="01_제철시금치_숏츠"; "00_대본","09_BGM_효과음","10_최종출력" | % { New-Item -ItemType Directory -Force "$r\$_" }; 1..8 | % { New-Item -ItemType Directory -Force ("$r\Scene_{0:D2}" -f $_) }
```
Windows CMD:
```bat
mkdir "01_제철시금치_숏츠\00_대본" "01_제철시금치_숏츠\09_BGM_효과음" "01_제철시금치_숏츠\10_최종출력" & for /L %i in (1,1,8) do mkdir "01_제철시금치_숏츠\Scene_0%i"
```
macOS Terminal:
```bash
mkdir -p 01_제철시금치_숏츠/{00_대본,09_BGM_효과음,10_최종출력,Scene_0{1..8}}
```

## Vrew 5분 완성 체크리스트
1. 새로 만들기 → 쇼츠(9:16) → "텍스트로 비디오 만들기" → full_script_vrew.txt 붙여넣기 (줄 = 클립)
2. AI 목소리: 밝은 30대 여성/남성, 속도 1.05~1.1x → 전체 길이 38초 내외 확인
3. 클립별 S0N_img.png 교체 (배경 채우기), 켄번스 줌 효과 적용
4. 자막: 굵은 고딕 70~80pt, 흰 글씨+검정 외곽선, 하단 1/3 / 키워드 노란색·빨간색
5. BGM: 밝은 어쿠스틱(저작권 무료), 볼륨 10~15%, 내레이션 우선
6. 효과음: S01 whoosh, S03~S05 ding
7. 내보내기: 1080×1920 MP4 → 10_최종출력/제철시금치_숏츠_v1.mp4
