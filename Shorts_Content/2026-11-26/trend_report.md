## 트렌드 1. 김장철 + 겨울 굴 + 노로바이러스 시즌의 겹침

| 트렌드 근거 | ① 2026 김장재료 수급안정대책이 11/9~12/6 시행 중이고, 가을배추 생산량 전망은 전년보다 18.5% 증가([세계일보 11/16](https://www.segye.com/newsView/20261116501842), [경향신문](https://khan.co.kr/article/202611030809001)). ② 서울시가 2026-11-16자로 겨울철 영유아 노로바이러스 주의보 공지([서울시](https://news.seoul.go.kr/welfare/archives/574952)). ③ 식약처는 '가열조리용', '익혀 먹는' 표시가 있는 굴은 중심온도 85℃에서 1분 이상 가열하라고 안내([식약처 웹진](https://www.mfds.go.kr/webzine/202411/sub01.html), 검색 인용 기준) |
| 참고 자료 | [SBS Biz: 생굴 완전히 익혀드세요](https://biz.sbs.co.kr/amp/article/20000146075), [이투데이: 굴·복어·과메기 주의사항](https://www.etoday.co.kr/news/view/1973180) |
| 활용된 훅 | 언론 제목 패턴: "한겨울에도 살아남는 ○○", "먹기 전 ○○ 살피세요" → **경고 + 확인 행동** 구조 |
| 건강 채널 적용 | "김장날 생굴, 포장지 뒷면부터 보세요"처럼 **하나의 행동(표시 확인)** 을 첫 장면에 보여주기 |
| 지속 가능성 | **계절 반복형(강함)**. 매년 11~2월에 다시 쓸 수 있음. 김장 키워드는 11월 하순~12월 초에 정점(추정) |

| 트렌드 근거 | 위키트리가 유튜브 채널 영상을 인용한 귤 관련 기사를 짧은 간격으로 계속 내고 있음([1](https://www.wikitree.co.kr/articles/1109651), [2](https://www.wikitree.co.kr/articles/1111389), [3](https://www.wikitree.co.kr/articles/1173826)). **조회수 데이터는 확인 불가.** 언론이 반복해서 다루는 것을 수요 신호로 판단함(추정) |
| 활용된 훅 | "귤은 딱 '2개' 먹고 멈추세요", "일단 냉동실에 넣으세요…왜 몰랐나" → **숫자 제한형 + 의외 행동형** |
| 건강 채널 적용 | 꿀팁 채널이 다루지 않는 **근거 쪽**을 맡기: 카로틴혈증과 황달을 구별하는 법([Cleveland Clinic](https://health.clevelandclinic.org/carotenemia)), 당 함량 |
| 지속 가능성 | 겨울 시즌형(12~2월 강세, 추정) |
