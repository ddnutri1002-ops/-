# 6) 영상 편집 지침 + 7) 업로드 패키지

## 6) 영상 편집 지침

| 항목 | 지침 |
|---|---|
| 영상 길이 | 40~42초 (60초를 넘기지 말 것) |
| 컷 타이밍 | S1 0–4 / S2 4–10 / S3 10–18 / S4 18–23 / S5 23–30 / S6 30–35 / S7 35–38 / S8 38–42초. 각 장면 안에서 2~3초마다 줌이나 패닝으로 변화 주기 |
| 자막 위치 | 화면 아래쪽 약 70~78% 높이(오른쪽 UI 버튼과 하단 제목 영역을 피할 것). 핵심 키워드 자막은 위쪽 15% 영역에 크게 |
| 자막 스타일 | 흰 글씨 + 검은 외곽선 8px, 산돌/프리텐다드 계열 Bold, 한 줄 12자 이내 |
| 강조 단어 (노란색) | **가열조리용**, **익혀 먹는**, **노로바이러스**, **85℃ 1분**, **✕ 소독**, **비누 30초** |
| 효과음 | 정지 "띵"(S1), 뒤집기 "휙"(S2), 저음 "두둥"(S3), 오답 버저(S4), 보글보글(S5), 차임(S6), 물소리(S7), "뿅"(S8). 효과음 볼륨은 내레이션보다 -12dB |
| BGM 분위기 | 따뜻하고 경쾌한 어쿠스틱·우쿨렐레 계열(저작권 무료: YouTube 오디오 보관함). S3~S4는 살짝 긴장감 있게, S5부터 다시 따뜻하게. 볼륨 -22dB |
| 화면 움직임 | S1 천천히 줌 인 → 젓가락이 멈출 때 순간 줌 펀치(110%), S2 라벨 쪽으로 줌, S4 레몬 장면은 0.5초 단위 빠른 컷, S5는 김이 올라가는 쪽으로 위로 패닝, 나머지는 Ken Burns 효과(100→108%) |
| 전환 | 기본은 하드 컷. S2 플립, S5 와이프, S6 디졸브, S8 페이드 아웃만 사용(전환 효과를 많이 쓰지 않기) |
| 아이콘 | S5 온도계 아이콘 + "85℃" 텍스트, S7 타이머 아이콘 "30초", S3 화면 하단에 작은 글씨 "출처: 식약처" |
| 쉬운 구현 방법 | **CapCut / Vrew:** 대본을 넣어 TTS(차분한 30~40대 여성 또는 남성 목소리, 속도 1.1배) 생성 → 장면 이미지 8장 배치 → 자동 자막 후 강조 단어만 색 변경 → 키프레임 줌. 이 순서로 30분 안에 완성 가능 |
| 반복 시청 장치 | 마지막 장면(김장 가족)과 첫 장면(김장 상차림)의 색감을 맞추면 루프 재생이 자연스러워짐 |

## 7) 업로드 패키지

### 유튜브 제목
**김장날 생굴, 포장지에 '이 말' 있으면 날로 드시면 안 됩니다 #굴 #노로바이러스**

### 설명란
```
김장날 보쌈에 곁들이는 생굴, 먹기 전에 포장지부터 확인해 보세요.

✅ '가열조리용', '익혀 먹는' 표시 → 속까지 85℃에서 1분 이상 익혀 먹기 (식약처 안내)
✅ 레몬즙·초장·술은 소독 수단이 아니에요
✅ 생식용 굴이라도 영유아, 어르신, 임신부, 면역력이 약한 분은 익혀 먹는 편이 더 안전해요
✅ 굴을 만진 뒤에는 비누로 흐르는 물에 30초 이상 손 씻기

구토, 설사 증상이 있다면 그날은 조리에 참여하지 말고, 증상이 심하거나 오래가면 의료기관을 찾으세요.
이 영상은 일반적인 식품 안전 정보이며 의학적 진단을 대신하지 않습니다.

📚 참고 자료
- 식품의약품안전처 굴 섭취 안내
- 미국 CDC, Vibrio and Oysters
(자세한 링크는 고정 댓글에 있어요)

#굴 #생굴 #김장 #노로바이러스 #식중독예방 #겨울제철 #굴국밥 #건강정보 #식품안전 #shorts
```

### 업로드 시 참고사항
- **업로드 시간:** 김장은 주로 주말에 하므로 **금요일(11/27) 저녁 6~8시** 또는 토요일 오전 업로드를 추천합니다(추정. 채널 Analytics에서 시청자가 활동하는 시간을 확인 후 조정).
- 시즌이 길어서 12월 초에 노로바이러스 관련 뉴스가 나오면 커뮤니티 탭이나 관련 영상으로 다시 홍보하기
- **AI 생성 콘텐츠 공개:** 실사처럼 보이는 합성 장면을 넣는다면 유튜브의 '변경되었거나 합성된 콘텐츠' 공개 옵션 확인하기(3D 캐릭터만 쓴다면 일반적으로 해당 없음. 최신 정책 확인 권장)
- 건강 관련 콘텐츠이므로 "치료", "예방 100%" 같은 표현은 제목, 설명, 썸네일 어디에도 쓰지 않기
- 업로드 전에 식약처 원문 페이지에서 85℃·1분 기준을 한 번 더 확인하기(이번 조사에서는 원문 페이지에 직접 접속하지 못함)
- 후속 시리즈 제안: "생굴에 레몬 뿌리면 안전하다?"(후보 7) → "노로바이러스, 손 소독제만으로 될까?"(후보 10)
